## Hi, I'm Tee San

Full-stack developer and data engineer based in Indonesia (UTC+7). I build the internal systems that plants and service businesses run on every day: production planning, workforce attendance, approvals and warehouse stock, plus the integrations that move their data into SAP.

I was the only internal developer behind a production system used daily across four plant sites, from architecture and database design to the SAP S/4HANA integration and deployment.

**Open to** full-time, contract and remote roles, and to freelance projects.
[Portfolio](https://porto.hillteo.com) · [teesanfajar@gmail.com](mailto:teesanfajar@gmail.com)

### What I work on

- **Manufacturing operations**: work orders, labor and machine hours, bay scheduling, early-warning monitoring and SPC charts.
- **Enterprise integration**: automated posting to SAP S/4HANA with retry, correction and an operations queue, optionally over Apache Kafka.
- **Workforce apps**: mobile check-in with face verification and GPS, shifts, overtime approvals, multi-site time zones.
- **Business workflows**: approvals, evidence capture and reports, including Microsoft Power Apps code apps on SharePoint and Power Automate.
